## Verification policy

Record only checks actually run. Successful MP4 output verifies rendering and media metadata; it does not prove pedagogical or mathematical correctness. Known sample scalar claims are checked separately in `verify_sample_math`. The ten manual evaluation cases include changed coefficients and physical assumptions to check whether generation adapts beyond a reference example.

Repair control flow is exercised with injected renderer failures: exact traceback propagation, successful subsequent render, maximum retry count, and timeout handling. Live Gemini repair requires a user-supplied key and is not implied by mocked tests.

No training dataset, fine-tuning, paid model fallback, public deployment, or automatic mathematical proof system is included. Code validation is not advertised as a security sandbox.
